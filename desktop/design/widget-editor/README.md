# Menu bar popup widget editor

Selected direction: **option 2**, `option-2-canvas.png` (the second image displayed during ideation).

The existing light Settings window becomes a focused editing canvas. A live miniature Dashboard sits in the center; the searchable widget library opens on the right. Add by button or drag, reorder using handles or arrow keys, remove widgets, restore the default draft, and save with Done. The insertion line, lifted card, disabled added state, and last-widget protection make changes visible before saving.

The library contains overview, daily trend, model distribution, activity, token mix, devices, cache hit rate, and output tokens. The preview reuses the bundled Dashboard and its actual local/synced data. Presentation settings preserve the shared CLI's configuration and authorization.

The original mock contains illustrative data and mixed-language labels. The implementation uses the selected App language, canonical Dashboard labels and real data. The Settings shell stays light; the preview supports the configured popup theme. Smaller windows use a closable overlay drawer.

The other generated options are retained as design history. Native captures of personal Settings are local-only. See the repository-root `design-qa.md` for visual comparison and validation evidence.
